## What you will learn

- **Docker** — install the Engine and Docker Desktop, run your first container, manage images,
  volumes and networks, and harden the daemon for production use.
- **Kubernetes** — set up a cluster, deploy and scale workloads, manage configuration and secrets,
  and verify a cluster with `kubectl`.
- **Helm** — package, version and release applications with charts, repositories and rollbacks.
- **Istio** — install a service mesh, define traffic policies, and secure service-to-service traffic.
- **Minikube** — run a fully featured Kubernetes cluster locally for fast iteration.
- **OpenShift** — install the platform and learn the workflow for deploying containerised apps.

## Prerequisites

Most guides assume:

- A 64-bit processor with at least 4 GB of RAM
- Linux, macOS or Windows with administrator access
- Basic familiarity with a terminal and shell scripting
