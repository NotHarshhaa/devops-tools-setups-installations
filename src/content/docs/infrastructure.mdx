These guides cover the tools that make that possible — from provisioning to secret management and
golden image building.

## What you will learn

- **Terraform** — initialise workspaces, model resources in HCL, plan safely and apply changes.
- **Ansible** — write inventories and playbooks, and configure fleets of hosts idempotently.
- **Vault** — enable secret engines, issue dynamic credentials and audit access.
- **Consul** — provide service discovery and distributed configuration.
- **Vagrant** — spin up reproducible development environments from code.
- **Packer** — build golden machine images for every target platform.

## Safe rollout principles

1. Commit infrastructure code and review it like application code
2. Always run `plan` (or `--check`) before applying
3. Keep state in a remote, versioned backend
4. Store credentials in Vault or your cloud secret manager — never in `.tfvars`
5. Roll out incrementally with canaries and blue/green releases
