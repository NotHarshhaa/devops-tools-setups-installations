## What you will learn

- **GitHub Actions** — write workflows, choose the right runner, cache dependencies and reuse
  workflows across repositories.
- **GitLab CI** — configure runners, structure jobs into stages and ship a pipeline with
  `.gitlab-ci.yml`.
- **Jenkins** — install the controller and agents, unlock the setup wizard and run a first
  declarative pipeline.

## Pipeline checklist

1. Lint and unit test on every push
2. Build an immutable artifact once and promote it through environments
3. Cache dependencies to keep builds fast
4. Store secrets in the platform secret store — never in the repository
5. Gate deployments with approvals for production releases
